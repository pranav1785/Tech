# Tech Guilds IITM

A responsive static showcase for the IIT Madras Tech Guilds ecosystem.

## Deploy on Vercel

1. Import `pranav1785/Tech` in Vercel.
2. Keep **Framework Preset** as `Other`.
3. Leave the build command and output directory blank.
4. Click **Deploy**.

No environment variables or backend services are required.

## Local preview

Open `index.html` directly, or run any static file server in this directory.

## Structure

- `index.html` — page content and metadata
- `styles.css` — responsive design system and layout
- `script.js` — menu, filters, reveal motion and header state
- `vercel.json` — zero-configuration Vercel hosting settings

The guild names are a representative first version. Replace them with the official roster before treating the page as an authoritative directory.
